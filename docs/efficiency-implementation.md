# Efficiency and acceptance controls

Approved scope: the September 29 session audit and the owner's request to apply
its recommendations. Preserve independent review and public-surface QA.

1. Bind checks to the actual worktree and support explicit commands and Python
   3.11+. Verify with broken candidate / passing parent and Make-only fixtures.
2. Validate task contracts, named cases, real versus synthetic witnesses, graph
   capabilities and exact-candidate receipts. Verify negative CLI cases.
3. Resolved in 0.15: see the `when:` flags in `graphs/feature.md` and the engine's step 4 (`docs/engine/run.md`).
4. Repair backend response contracts, add Bruno cases with an isolated Temporal
   harness, and gate a committed schema snapshot. Verify HTTP/SSE boundaries.
5. Gate frontend unit, schema-consumer and mock-browser cases in CI. Verify
   non-empty artifact rendering and report completeness without shared services.
6. Wire profiles and local installation, independently review patches, run
   required checks, and publish reviewable branches with the personal GitHub
   account for Graph Engineering.

Cost evidence is measured from frozen session records, not a reconciled bill.
Cache-TTL changes require provider support and a measured coordinator-only trial;
no projected saving is reported as realized. Browser mocks and workflow activity
fakes prove bounded contracts, not real scanner or production deployment behavior.
